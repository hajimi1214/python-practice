# 练习场

这里不是教程，是**判题器**。

你写完代码，敲一行命令，它告诉你哪题过了、哪题错在哪。就这一个作用。

**今天（11/4，W1 最后一天）只需要做两题**：第 4 题和第 2 题。做完这两道，W1 就不算白过。

---

## 三步开始

**第 1 步**：用 VS Code 打开这个文件夹
（VS Code → 文件 → 打开文件夹 → 选 `练习场`）

**第 2 步**：打开 `01_W1_函数.py`，找到第 1 题，把那行

```python
raise NotImplementedError("第 1 题")
```

**整个删掉**，换成你自己的代码。

**第 3 步**：保存，在 VS Code 的终端里敲

```
python 跑一下.py
```

没有 VS Code 也行：进到 `练习场` 文件夹，地址栏敲 `cmd` 回车，再敲上面那行。

## 三条规则

**一、不许复制答案。**
一个字母一个字母敲。最常见的错不是逻辑，是中文引号、大小写、冒号写成中文冒号——手敲一次就永远记住了。

**二、一次最多做三题。**
做多了第二天不想开电脑。今天两题收工，明天自然想回来。

**三、每题最多给 30 分钟。**
超时就跳过，做下一题。`跑一下.py` 里的报错提示，八成已经说了问题在哪。

## 卡住了

| 情况 | 怎么办 |
|---|---|
| 判题器说 `[!!]` 报错 | 先看后面那句 `>>` 提示，它已经指出原因了 |
| 说 `[XX]` 但不知道错哪 | 提示里有「期望 X，你给的是 Y」，对照题目里的例子看 |
| 完全没思路 | 只问一句：「第 3 题要求 XX，我写了 YY，报错是 ZZ，错在哪一行」，把完整报错贴上 |
| 想放弃了 | 只做第 4 题。for 循环打印一个列表，三行代码，今天就算有产出 |

**别问 AI「帮我写这一题」。** 一问就有答案，一有答案就学不会。这是整个练习场唯一可能需要你克制的诱惑。
